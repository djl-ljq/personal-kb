# 9｜验证与复盘

> 对照第 0 步的指标看效果，把经验写回方法层——这才形成闭环。

## 产出物

- 效果对照表（目标 vs 实际）、复盘三条（原判断/实际结果/下次改什么）、方法层修订

## 检查清单

- [ ] 对照第 0 步的指标逐条比对，不换指标
- [ ] 偏差写原因，不写感受
- [ ] 至少有一样东西回写进 `00`–`03` 或 `templates/`
- [ ] 复盘进 `journal/`，脱敏后再入库

## 常见坑

- 复盘写成「项目总结」，只记做了什么
- 只记结果不记当时的判断——下次照样错
