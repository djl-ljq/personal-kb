# Tasks：<能力名称>

> 从 Spec 派生。每颗任务 2–5 分钟能做完、能自证。
> 拆不出来，说明这颗还不够小；写不出验证步骤，说明还不知道什么叫做完了。

## 约定

- 每颗任务写三样：**改哪个文件** / **改成什么** / **怎么验证**。
- 标依赖：`[← T03]` 表示要等 T03 完成。
- 可并行的用 `‖` 标出。
- 一颗任务只做一件事。出现「并且」就该拆。
