# 8｜上线与交接

> 让它能跑、能回退、别人能接手。

## 产出物

- 部署记录、回退预案、权限移交清单、操作手册、监控与告警项

## 检查清单

- [ ] 回退步骤有人实际演练过，不是只写在文档里
- [ ] 权限按最小必要移交，不留后门账号
- [ ] 手册写的是操作步骤，不是架构介绍
- [ ] 「出问题找谁」写到人和联系方式

## 常见坑

- 把「部署成功」当上线完成
- 回退方案只写在文档里，从没跑过
- 交接只给一份架构图，没给账号和入口
