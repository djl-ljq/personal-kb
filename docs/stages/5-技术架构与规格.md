# 5｜技术架构 + 规格（SDD 起点）

> 选型、写规格、拆任务——让 AI 只读文档就能动手。

## 产出物

- 技术选型（难回退的配 ADR）、非功能要求、Spec、Tasks、接口契约

## 检查清单

- [ ] 七项要素齐全：数据模型/接口契约/状态流转/权限/异常恢复/验收标准/禁止 AI 自决
- [ ] 每条验收标准都能被一个测试判定真假
- [ ] 非功能四类写死：性能、安全、可用性、合规
- [ ] 难回退的选型有 ADR（含备选与否掉原因）

## 常见坑

- 规格里混进实现细节，AI 反而照着错的写
- 验收标准写成「体验流畅」「响应及时」
- 非功能留到开发阶段才想
