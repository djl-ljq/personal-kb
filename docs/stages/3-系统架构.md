# 3｜系统架构

> 决定分层、模块和集成边界，说清「谁跟谁说话、说崩了怎么办」。

## 产出物

- 系统架构图、模块清单、集成点清单（含鉴权方式与失败处理）

## 检查清单

- [ ] 每个集成点写清协议、鉴权方式、超时与失败行为
- [ ] 模块职责无重叠，边界处只有一个入口
- [ ] 存量系统只标「接口对接」，不顺手重构

## 常见坑

- 图上画了箭头，但没写协议和失败处理
- 把所有东西画进一张图，看不出层次
