# 7｜测试与验收（SDD Converge）

> 拿证据判定「做对了没有」，不靠感觉。

## 产出物

- 测试报告、缺陷清单、契约校验结果、AC 逐条结论

## 检查清单

- [ ] 每条 AC 都有明确结论，没有「大概可以」
- [ ] 接口契约/schema 校验通过（变更过的接口必查）
- [ ] 写明本轮回归范围与未覆盖部分
- [ ] 失败项写根因，不写「重跑一次就好了」

## 常见坑

- 测试全绿就交付——测试没覆盖的地方照样是坑
- 用同一个模型写代码又审代码，盲区重合
