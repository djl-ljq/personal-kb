# 0｜立项 · 定目标与范围

> 开工前把「为什么做、做到哪、什么不做、怎么算成功」定死，后面所有返工都从这一步少下来。

## 产出物

- 一页目标与边界声明：目标（客户原话）、可量化指标、明确不做的清单、关键假设

## 检查清单

- [ ] 目标能用一句对方原话复述，不用自己翻译
- [ ] 至少有一个可量化指标（数字+口径+时点）
- [ ] 「不做什么」写满三条以上
- [ ] 关键假设列出并附验证办法
- [ ] 拍板人写到人名，不写部门

## 常见坑

- 把「做个系统」当目标
- 指标写成「提升效率」「体验更好」
- 「不做什么」留空——这一栏留空，后面一定会加戏
